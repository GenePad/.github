## About

**GenePad** is a gene map editor built for everyday molecular biology work. Open plasmid maps, edit sequences, manage annotations, inspect restriction sites and review Sanger traces — all in one app for routine cloning design and checks.

## Features

| | |
|:---|:---|
| **Visualize plasmids instantly** | Import sequence files, view circular or linear maps, and jump between map, sequence and annotations |
| **Edit sequences with context** | Edit bases, inspect functional elements and manage annotations in one workspace |
| **Check enzymes & primers** | Display restriction sites and support primer design, fragment localization and cloning plan checks |
| **Inspect Sanger results** | Open AB1 files and check sequencing results against reference sequence and map context |

## Why GenePad?

- **Lightweight** — Focused on everyday plasmid viewing, editing and checking without making simple work feel complex
- **Cross-platform** — Available for Windows, macOS, Linux and Android across desktop and mobile
- **Familiar workflow** — Built around maps, sequences, annotations, enzymes, primers and sequencing results
