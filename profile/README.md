## 关于 | About

**GenePad（基因工坊）** 是一个面向日常分子克隆工作的基因图谱编辑器。打开质粒图谱、编辑序列、管理注释、查看酶切位点和 Sanger 测序结果——一个软件完成日常分子克隆设计与检查。

**GenePad** is a gene map editor built for everyday molecular cloning work. Open plasmid maps, edit sequences, manage annotations, inspect restriction sites and review Sanger traces — all in one app for routine cloning design and checks.

## 核心功能 | Features

| | |
|:---|:---|
| **立即查看质粒图谱** | 导入序列文件后，快速查看环状或线性图谱，并在图谱、序列和注释之间联动定位 |
| **带着上下文编辑序列** | 在同一工作区中编辑碱基、检查功能元件、管理注释，减少在多个软件之间切换 |
| **检查限制酶与引物** | 显示限制性内切酶位点，辅助引物设计、片段定位和克隆方案检查 |
| **查看 Sanger 测序结果** | 支持 AB1 文件查看，结合参考序列和图谱信息，更直观地检查测序结果 |

<details>
<summary>English</summary>

| | |
|:---|:---|
| **Visualize plasmids instantly** | Import sequence files, view circular or linear maps, and jump between map, sequence and annotations |
| **Edit sequences with context** | Edit bases, inspect functional elements and manage annotations in one workspace |
| **Check enzymes & primers** | Display restriction sites and support primer design, fragment localization and cloning plan checks |
| **Inspect Sanger results** | Open AB1 files and check sequencing results against reference sequence and map context |

</details>
