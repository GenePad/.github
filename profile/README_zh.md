## 关于基因工坊

**基因工坊 GenePad** 是一个面向日常分子克隆工作的基因图谱编辑器。打开质粒图谱、编辑序列、管理注释、查看酶切位点和 Sanger 测序结果——一个软件完成日常分子克隆设计与检查。

## 核心功能

| | |
|:---|:---|
| **立即查看质粒图谱** | 导入序列文件后，快速查看环状或线性图谱，并在图谱、序列和注释之间联动定位 |
| **带着上下文编辑序列** | 在同一工作区中编辑碱基、检查功能元件、管理注释，减少在多个软件之间切换 |
| **检查限制酶与引物** | 显示限制性内切酶位点，辅助引物设计、片段定位和克隆方案检查 |
| **查看 Sanger 测序结果** | 支持 AB1 文件查看，结合参考序列和图谱信息，更直观地检查测序结果 |

## 为什么选择基因工坊？

- **更轻量** — 聚焦日常质粒查看、编辑和检查，不让简单任务变复杂
- **真正跨平台** — 支持 Windows、macOS、Linux 和 Android，桌面和移动端都能使用
- **更贴近实验流程** — 围绕图谱、序列、注释、酶切、引物和测序结果组织功能
